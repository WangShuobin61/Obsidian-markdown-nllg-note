# 2. “FreeRTOS移植”高概率夸大

他在多个项目里写：

> 完成 FreeRTOS 的移植与裁剪

这个很值得重点打。

因为：

ESP-IDF 本身就已经集成 FreeRTOS。

很多人把：

- 创建任务
- 配置 heap
- 改 tick
- 调优栈

也写成“移植”。

真正的 FreeRTOS 移植：

- SysTick
- PendSV
- 上下文切换
- port.c
- heap_x.c
- 中断临界区
- Cortex-M ABI
- task stack frame

一般 3 年经验很少真正做过。

这个是重点鉴别点。

---

# 3. “OPUS 编解码 + WebSocket + AI语音”深度存疑

这个项目描述已经接近：

“小型 AI 智能音箱”。

### 他到底做了什么？

可能只是：

- 调 SDK
- 接 WebSocket
- 调接口

而不是：

- 音频 pipeline
- jitter buffer
- 音频同步
- 回声消除
- latency 优化

说明深度一般。
