# 4. ORB-SLAM3项目疑似“包装过度”

比如：

> 微秒级时间戳对齐

实际上：

```
message_filters::ApproximateTime
```

本身并不是微秒级同步。

属于典型包装用语。

---

再比如：

> 定位精度从0.735m降至0.029m

提升25倍。

如果没有论文或者实验支撑，数字可信度需要核验。
