# 十三、AI简历分析

这份简历有一个很明显的特点：**基础开发能力可能不差，但 ROS/机器人方向的真实性和深度需要重点核验。**

从履历看，他更像：

- Linux/C++基础开发工程师
- 国产桌面系统/中间件开发
- OCR/DLP业务开发
- 接触过 ROS2 概念

而不是一个典型的：

- SLAM/导航开发工程师
- 机器人算法工程师
- 机器人系统集成工程师

所以面试重点建议放在：

1. ROS2 真实使用深度
2. Linux/C++功底是否扎实
3. 是否能快速转机器人行业
4. 是否只是“会说概念”
5. 工程化能力是否达标
