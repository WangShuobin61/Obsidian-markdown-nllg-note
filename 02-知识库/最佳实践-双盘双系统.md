也就是说：

- `/mnt` → 管理员临时挂载测试用

- `/media` → 系统自动挂载可移动设备


从“教科书角度”来说：

> 你说得没错，固定磁盘挂 `/mnt` 更“传统”。

# 二、是谁决定左侧有没有磁盘图标？

在 Ubuntu 桌面（GNOME）里：

- 文件管理器是 Nautilus

- 设备管理由 UDisks 负责

- 底层设备事件来自 Linux 内核


流程是：

硬盘 → 内核识别  
→ UDisks 管理  
→ GNOME 显示为“设备”

---

# 三、为什么挂在 /mnt 不显示？

当你：

sudo mount /dev/xxx /mnt/data

这种方式属于：

> 手动 mount（管理员行为）

UDisks 不参与。

GNOME 认为：

> 这是系统内部目录  
> 不是“可插拔设备”

所以不会在侧边栏显示“磁盘图标”。

---

# 四、为什么挂到 /home 下会显示？

其实不是因为路径在 `/home`。

而是因为：

当你用文件管理器点击磁盘时，  
它是通过 UDisks 自动挂载的。

自动挂载路径通常是：

/media/用户名/磁盘名

这种挂载方式：

- 有 udisks 标记

- 带有 x-gvfs-show 元数据

- 被 GNOME 识别为“可移除设备”


所以就显示在左侧。

# 五、关键区别：mount vs udisks

|挂载方式|左侧是否显示|
|---|---|
|sudo mount|❌ 不显示|
|/etc/fstab 普通挂载|❌ 不显示|

# 一、为什么现在会显示？

GNOME（文件管理器是 Nautilus）  
会读取挂载点的 metadata。

只要：

- 是一个“独立文件系统”

- 可被当前用户访问

- 没被标记为隐藏


它就会在侧边栏显示为“设备”。

# 二、解决方法（推荐）

把你的 data 这一行改成：

UUID=4E201BA7201B9555  /home/nllg/data  ntfs3  defaults,uid=1000,gid=1000,x-gvfs-hide  0  0

保存后执行：

sudo mount -o remount /home/nllg/data

或者直接：

sudo mount -a

然后重新打开文件管理器。

# 三、x-gvfs-hide 是什么？

这是 GNOME 使用的一个挂载选项：

|选项|作用|
|---|---|
|x-gvfs-show|强制显示|
|x-gvfs-hide|强制隐藏|

它只影响桌面 UI，不影响系统使用。

- GNOME 默认对 `/mnt` 下的挂载不当作“用户设备”

- 或者之前没有被 gvfs 标记


路径只是间接因素。

真正控制显示的是：

> gvfs 元数据
