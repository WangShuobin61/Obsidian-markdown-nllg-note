### 命名规范


| 类型                         | 命名规则                            | 示例                          |
| -------------------------- | ------------------------------- | --------------------------- |
| 工作空间目录名                    | 小写(snake_case)_ws               | `wheel_scanning_ws`         |
| 功能包目录名                     | 小写(snake_case)_bringup          | `wheel_scanning_bringup`    |
| qml模块目录名                   | 简短合成词小写(snake_case)             | modeule                     |
| cpp文件名                     | 全小写或小写蛇形                        | `database.cpp`              |
| QML文件名                     | 大驼峰                             | `WheelScanningSystem.qml`   |
| 类 (class)                  | 大驼峰                             | `WheelScanningSystem`       |
| 结构体                        | 大驼峰                             | `WheelScanningSystemStatus` |
| 枚举（enum）                   | 大驼峰                             | ProcessState                |
| 类型定义（typedef）              | 大驼峰                             | WheelScan                   |
| 枚举项                        | 全大写                             | PROCESS_STATE_UNKNOWN = 0   |
| LLVM风格 函数名                 | 小驼峰                             | void dataBase()             |
| Google C++风格函数名            | 一般 大驼峰                          | void DataBase()             |
| Google C++ <br>存取函数 内联/短函数 | 匹配变量名                           | num_entries()               |
| 变量名                        | 小驼峰                             | `ultrasonicCount`           |
| 成员变量                       | m_+小驼峰                          | `m_indicatorState`          |
| 全局变量                       | g_+小驼峰                          | `g_systemStatus`            |
| URI(与源码目录强绑定)              | 全小写(反向域名风格)<br>和Java、Android包类似 | wheelscanning.module        |


.clang-format 格式控制文件
```.clang-format
# ===============================
# Qt Project Clang-Format Config
# ===============================

# 基于 LLVM 风格
BasedOnStyle: LLVM

# 使用 4 空格缩进（Qt 常见）
IndentWidth: 4
  
# 每行最多 120 字符（适配 27 寸显示器）
ColumnLimit: 120 

# K&R 大括号风格（Qt 官方风格）
BreakBeforeBraces: Attach  

# 允许短函数写成一行（getter/setter 更紧凑）
AllowShortFunctionsOnASingleLine: All

# 指针左对齐：int* ptr; (社区主流风格)
PointerAlignment: Left

# 自动排序 include 语句（Qt 推荐）
SortIncludes: true
```
