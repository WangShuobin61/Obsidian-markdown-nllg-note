# 团队仓库配置与使用指南

## 概述

本指南将帮助您配置本地git仓库，使其可以推送到团队仓库，满足公司将代码推送到NAS上Gitea服务的要求。

## 配置步骤

### 1. 前提条件

- 已在公司NAS上的Gitea服务中加入团队（组织）
- 需要知道NAS的IP地址和Gitea服务的端口号 192.168.33:3000

### 2. 在Gitea上创建仓库

在开始之前，请先在Gitea上手动创建团队仓库：

- **团队仓库**：在团队（组织）下创建仓库，如命名为"sx_project"

### 3. 配置远程仓库

使用我提供的脚本快速配置团队仓库：

```bash
# 1. 编辑脚本，替换为实际的Gitea服务URL和实际组织名和用户名
nano setup_remote_repos.sh

# 2. 找到以下行，替换为您的实际仓库URL，包括组织名和项目名 更改gitea的用户名和邮箱
第15行 ：TEAM_REPO_URL="http://192.168.33:3000/组织名/项目名.git"
第86行 ：git config --global user.name "你的gitea名字"
第87行 ：git config --global user.email "创建gitea账户时配置的邮箱"

# 3. 保存并退出编辑器（按Ctrl+O保存，Ctrl+X退出）

# 4. 运行脚本配置远程仓库
./setup_remote_repos.sh
```

这个脚本会自动执行以下操作：

```bash
# 配置团队仓库为远程origin
git init
touch .gitignore
touch README.md
git remote add origin $TEAM_REPO_URL

# 配置全局git用户名和邮箱
git config --global user.name $GIT_USERNAME
git config --global user.email $GIT_EMAIL
```



### 4. 首次推送代码

配置完成后，执行以下命令首次推送代码：

```bash
# 推送到团队仓库（首次需要设置上游分支）
git push -u origin master
```

## 日常使用流程

### 推送更新到团队仓库

日常开发完成后，使用我提供的同步脚本来推送到团队仓库：

```bash
./sync_all.sh
```

这个脚本会自动执行以下操作，同样你也可以自行操作：

```bash
# 添加所有修改的文件
git add .
git commit -m "一键提交.sh"
git push origin master
```

### 从远程仓库拉取更新

如果有其他人修改了远程仓库，您可以使用以下命令拉取更新：

```bash
# 从团队仓库拉取
git pull origin master
```

## 常见问题与解决方案

### 1. 推送失败

如果推送失败，可能的原因包括：
- Gitea服务URL配置错误
- 网络连接问题
- 权限不足（请确保您有团队仓库的推送权限）
- 本地分支与远程分支存在冲突

### 2. 如何获取NAS的IP地址和Gitea端口

请咨询公司IT部门或管理员获取NAS的IP地址和Gitea服务的端口号。

### 3. 如何检查当前远程仓库配置

使用以下命令查看当前配置的远程仓库：

```bash
git remote -v
```

### 4. 如何修改已配置的远程仓库URL

如果需要修改远程仓库的URL，可以使用以下命令：

```bash
git remote set-url origin 新的团队仓库URL
```

## 脚本说明
